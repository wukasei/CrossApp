# CrossApp
Наскрізний проєкт з крос-платформного програмування.
Предметна область: Бібліотека. Сутності: Book, BookCopy, Reader, Loan.
Призначення: облік видач примірників книг читачам.

## Запуск
```bash
dotnet build
dotnet run --project src/Cli
```

## Середовище
.NET SDK 10.0, Windows 11 x64 

## Порівняння розмірів Self-Contained публікацій
* **win-x64:** 70,50 MB
* **linux-x64:** 70,51 MB

Розміри каталогів практично ідентичні (різниця менше 0.1 MB), оскільки базовий склад нативного середовища виконання .NET Runtime (CoreCLR, компілятор RyuJIT та набір системних бібліотек BCL) оптимізовано однаково для обох платформ x64.
